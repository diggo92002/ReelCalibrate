# 捲線器誤差換算

純 HTML、CSS、JavaScript 的手機網頁，無須安裝套件或執行建置。

## 功能

- 第一組：現有米數 × 倍數 = 實際米數，預設倍數 **0.66**。
- 第二組：實際米數 × 倍數 = 要放米數，預設倍數 **1.5**。
- 左欄輸入米數，中欄顯示結果，右欄修改倍數。
- 點選米數或倍數後彈出數字鍵盤，支援整數與小數。
- 倍數保存在目前裝置的瀏覽器中，清空米數不會重設倍數。
- 支援加入手機主畫面；在 HTTPS 網站首次成功載入並完成快取後，可離線換算。

## 上傳的檔案

將以下檔案放在 Git 儲存庫的根目錄：

```text
index.html             網頁主程式（含樣式與數字鍵盤）
manifest.webmanifest   手機主畫面名稱與圖示設定
sw.js                  離線快取
README.md              專案說明
.gitignore             Git 排除規則
icon-192.png           稍後補上，192 × 192 像素
icon-512.png           稍後補上，512 × 512 像素
```

圖示檔名區分大小寫，請使用以上名稱，並放在與 `index.html` 相同的位置。兩張圖示已預先設定好引用，不需要修改程式。尚未補圖時仍可使用換算功能，網站圖示及主畫面安裝圖示可能無法正常顯示。

## 開啟與部署

直接用瀏覽器開啟 `index.html` 可預覽換算功能。主畫面安裝及離線功能請在部署後的 HTTPS 網址測試。

此專案不需要建置。使用靜態網頁代管時，發布儲存庫根目錄，首頁為 `index.html`。所有資源均使用相對路徑，可部署在網站根目錄或儲存庫子路徑。

Git 儲存庫用來保存檔案；手機要透過網址使用，還需要啟用網站代管。

## 手機主畫面

圖示補齊並完成 HTTPS 部署後，可使用手機瀏覽器的「加入主畫面」或「安裝」功能；實際選項依瀏覽器而異。iPhone 主畫面圖示引用 `icon-192.png`。

## 更新與資料

- 更新網站內容時，請同步修改 `sw.js` 裡的 `CACHE_NAME` 版本，例如將 `v1` 改為 `v2`。
- 倍數依瀏覽器與網站來源分開保存；清除網站資料或改用其他裝置不會沿用設定。
- 米數與倍數限非負數，每次輸入最多 24 個字元（含小數點）。
- 兩組換算獨立計算，輸入數值不會傳送到伺服器。
